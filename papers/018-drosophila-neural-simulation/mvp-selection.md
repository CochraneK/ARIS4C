# ARIS4C018 · MVP Selection Framework

## Goal

Choose the first runnable simulation by scientific value, not by technical complexity.

## Candidate ranking

### A. Central complex navigation

Current priority candidate.

Why:

- clear behavioural output;
- strong connection to connectome resources;
- links naturally to computational principles such as path integration and control.

Minimum experiment:

```
small circuit model
        ↓
external stimulus
        ↓
network activity
        ↓
navigation-related output
```

### B. Mushroom body learning

Potential value:

- connects biology and reinforcement learning;
- interpretable learning rules.

Risk:

- behavioural modelling may require more assumptions.

### C. Whole-brain simulation

Not first target.

Reason:

- computationally expensive;
- difficult to connect simulation output to scientific claims.

## Current decision

Proceed first with circuit-level models.

The first successful MVP should answer:

"Can a biologically constrained small circuit reproduce an interpretable computational function?"
