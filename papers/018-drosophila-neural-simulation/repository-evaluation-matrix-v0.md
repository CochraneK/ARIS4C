# ARIS4C018 · Repository Evaluation Matrix v0

## Evaluation criteria

| Dimension | Question |
|---|---|
| Runnable | Can one person run it locally? |
| Data | Is public data available? |
| Interpretability | Does it connect to a biological question? |
| Intervention | Can parameters/circuits be changed? |
| Visualization | Can behaviour and neural state be shown together? |
| Extensibility | Could it become an independent project? |

## Preferred project profile

Highest priority:

```
behaviour
    +
neural activity
    +
perturbation
    +
visual feedback
```

## Current search categories

### Circuit simulation

- central complex models

### User-facing projects

- interactive brain viewers
- browser neuroscience demos
- educational simulations
- behaviour-neural activity visualizations

## Selection rule

A project is prioritized when it can move from:

```
clone
 -> run
 -> modify
 -> observe
 -> ask a scientific question
```

rather than only reproducing an existing result.
