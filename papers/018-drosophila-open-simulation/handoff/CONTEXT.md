# ARIS4C018 · Context

The project originated from interest in open Drosophila simulation ecosystems and especially visual systems that show a moving fly beside changing neuronal activation. The goal is to learn from strong existing open projects, reproduce them, inspect what other users have built on top of them, and then use the combined technical/scientific map to discover worthwhile research questions.

Avoid turning the project into a software popularity list. Scientific reuse, provenance, reproducibility and falsifiability matter more than stars.
