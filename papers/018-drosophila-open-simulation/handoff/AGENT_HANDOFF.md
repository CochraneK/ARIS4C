# ARIS4C018 · Agent handoff

## Mission

Turn open Drosophila simulation/connectome/behavior ecosystems into a reproducible experimental substrate, then derive and pilot falsifiable scientific questions.

## Current state

The project is a concept scaffold. Do not claim that a repository has been reproduced until exact install/run evidence exists in Git.

## Next bounded unit

1. define a structured repository atlas;
2. identify high-value upstream and downstream projects;
3. reproduce two complementary examples;
4. prototype or specify the fly-motion × neural-activity coupling;
5. freeze a shortlist of candidate questions.

## Guardrails

- distinguish real biological/neural output from illustrative animation;
- preserve licenses and provenance;
- prefer executable evidence over screenshots;
- avoid treating GitHub popularity as scientific quality.
