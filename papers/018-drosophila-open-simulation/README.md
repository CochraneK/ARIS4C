# ARIS4C-018 · Drosophila Open Simulation

ARIS4C018 is a discovery-driven computational-neuroscience project centered on open Drosophila simulation, behavioral control, and brain/neuronal activity visualization.

The project has two linked goals:

1. build an auditable atlas of reusable open-source Drosophila simulation / connectome / behavior projects and reproduce representative examples;
2. use those reproducible systems to generate and test genuinely interesting scientific questions rather than treating the repository survey itself as the endpoint.

A preferred public-facing interaction pattern is a synchronized view in which a fly moves on one side while neural/neuronal activation is shown on the other.
