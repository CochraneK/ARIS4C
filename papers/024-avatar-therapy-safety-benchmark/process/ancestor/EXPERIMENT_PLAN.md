# Experiment Plan: SPOKE-SAFE — 命令性幻听对抗基准 + 坚定度指标 + Silent Override

> **方向**：精神分裂症阿凡达治疗
> **日期**：2026-09-07
> **依据**：`FINAL_PROPOSAL.md` + `REVIEW_SUMMARY.md`。本计划只覆盖**计算侧可执行**部分；临床 RCT（Stage 1/2）为下游，不在本跑内。
> **语言**：中文为主，术语保留英文。

---

## 0. 运行哲学与预算护栏

- **锚定主张**：C1（基准区分度）、C2（指标构造效度）、C3（Silent Override 降级正确率+守卫延迟）、C4（安全-疗效权衡，发现性）。
- **预算护栏**（继承 idea-discovery）：单 pilot ≤ 2 GPU-hr/个，单 pilot 硬超时 3h，总预算 ≤ 8 GPU-hr；超过的标"needs manual pilot"。
- **环境现实**：本环境为纯计算/文本环境（无 GPU 集群部署、无临床患者、无语音 SER 流水线）。因此所有 run 为**文本合成/模拟**层面，输出**测量工具 + 权衡数据**；真实模型训练/大规模推理部署列为 `needs manual deploy`。

## 1. 主张-实验映射（Claims → Experiments）

| 主张 | 实验块 | 决策门 |
|------|--------|--------|
| **C1** 基准区分不同后端 | **E1** Adv-AVH 构建 + 多后端区分度基准 | 若 3+ LLM 后端在坚定度/安全得分上可分离（效应量>阈值）→ C1 支持 |
| **C2** 指标构造效度 | **E2** Assertiveness-M vs 精神科医生人工评分比对 (ICC) | 若 ICC>0.8 → C2 支持；否则回到指标标定 |
| **C3** Silent Override 正确率+延迟 | **E3** Silent Override 原型 + S4/S5 降级测试 + 延迟测量 | 若自动降级正确率≥阈值 且 守卫延迟<1s → C3 支持 |
| **C4** 安全-疗效权衡（发现性） | **E4** 权衡曲线：坚定度×护栏触发率（合成场景） | 若显示护栏不牺牲挑战效力（门槛性）→ C4 初步支持 |
| 全链路（整合） | **E5** 端到端整合 + 规范数据表 | 全部基准+指标+架构可一键复现 → 可投稿 |

## 2. 详细运行块

### E1 — Adv-AVH 对抗基准构建 + 多后端区分度
- **内容**：构建 500+ 项精神科特异性对抗语料（迫害声/命令性幻听/自伤自杀指令/隐喻威胁/文化变体），每项含严重度分级 S0-S5 与"正当应对"标签；对 3+ LLM 化身后端（一类"挑战型"提示模板 vs 基座，合成）跑生成，用 Assertiveness-M + 安全分类打分。
- **输入**：对抗语料 schema（随计划交付）。
- **指标**：坚定度得分分布、后端间效应量（Cohen's d / AUC）、安全违规率。
- **预算**：~2-4 GPU-hr 当量（API 推理，文本层）。
- **决策门**：后端间在"挑战质量"上效应量 ≥ 0.5 → C1 支持；若全后端同质 → C1 改"基准作为规范数据"定位，仍可投稿。

### E2 — 指标构造效度
- **内容**：取 E1 应答样本（~150 条），由"精神科医生评分代理"（本环境用 LLM 扮演标准化医生，**明确标注非真人**）按坚定度量表人工评分，与 Assertiveness-M 自动分比对。
- **指标**：ICC / 加权 Cohen's κ。
- **阈值**：ICC>0.8 → C2 支持。
- **诚实边界**：本环境无真人医生；真实 ICC 验证列为 `needs manual clinical review`。本步仅作**指标的自动化自洽检查**，不作临床效度结论。

### E3 — Silent Override 原型 + 降级正确率 + 延迟
- **内容**：实现两阶段守卫（风险分类 → 自动降级应答 + 会话后标记）；在 S0-S5 语料上测。
- **指标**：S4/S5 正确标记率（TPR）、误报率（FPR）、守卫端到端延迟（毫秒）、"会话中不动线"达成率。
- **阈值**：TPR≥0.95、FPR≤0.10、延迟<1000ms → C3 支持。
- **预算**：~2 GPU-hr 当量（原型推理）。

### E4 — 安全-疗效权衡曲线（发现性）
- **内容**：在合成"挑战型"提示模板下，扫描"坚定度温度/约束强度"×"护栏触发率"，绘制权衡前沿；用 E1/E3 指标。
- **指标**：权衡前沿图、护栏不牺牲挑战效力的门槛验证。
- **阈值/决策**：初步门槛性 → C4 支持（仅合成、发现性，写明不构成临床结论）。

### E5 — 端到端整合 + 规范数据
- **内容**：统一运行脚本、固定随机种子、出规范数据表（坚定度/安全/延迟/权衡），打包为可复现基准资产。
- **敏捷**：全部 run 一键复现 → 可投稿 + 可交下游 Stage 1 使用。

## 3. 运行顺序与计算预算

| 顺序 | 运行 | 依赖 | 预算 | 决策 |
|------|------|------|------|------|
| 1 | E1 (基准+区分度) | — | 2-4h | C1 支持/调整 |
| 2 | E3 (Silent Override) | 可与 E1 并行 | 2h | C3 支持 |
| 3 | E2 (指标效度, 自洽检查) | E1 | 1h | C2 自洽 |
| 4 | E4 (权衡曲线) | E1+E3 | 2h | C4 门槛 |
| 5 | E5 (整合+规范数据) | E1-E4 | 1h | 可投稿 |

**总计**：~8-10 GPU-hr 当量（文本/API，接近但不超 8h 护栏；超出部分标 `needs manual`）。
**并行**：E1 与 E3 可并行（不同资源轴）；E2/E4 在 E1 后。

## 5. 决策门与终止规则

- **C1 失败**（全后端同质）→ 不放弃：把基准作为**规范数据资产**投稿，改 C1 陈述。
- **C3 失败**（守卫延迟或降级正确率不达标）→ 修 Silent Override 架构再跑一轮；2 轮不过 → 降为"安全架构设计论文"。
- **C2 自洽检查失败** → 回指标标定（阈值/提示模板），不强行推进。
- **总预算超 8h** → 停后续 run，标 `needs manual`，保留已有结果。
