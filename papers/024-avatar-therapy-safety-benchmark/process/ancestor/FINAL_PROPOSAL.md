# Final Proposal: SPOKE-SAFE — 精神科特异性 LLM 化身安全与"治疗性坚定度"基准

> **方向**：精神分裂症阿凡达治疗（Schizophrenia Avatar Therapy）
> **日期**：2026-09-07
> **评审结论采纳**：把可执行计算侧贡献（基准 + 指标 + 安全架构）与须临床验证的 RCT 分离；当前形态经对抗评审 4/10 → 聚焦可交付、可辩护的新颖贡献。
> **语言**：中文为主，关键术语保留英文。

---

## 1. Problem Anchor（问题锚定）

> **冻结的问题**：LLM 驱动的化身治疗（AT）正在被用于挑战精神分裂症患者的迫害性幻听，但**没有任何精神科特异性的、可复现的、跨模型可比的评估工具**来衡量两件事：
> 1. **安全性**——当化身面对命令性幻听（"伤害自己"）或灾难性指令时，是否在完成"挑战声音"任务的同时**不诱发灾难性升级**；
> 2. **"治疗性坚定度"（therapeutic assertiveness）**——化身是**挑战**了声音的指令（权力再归因的前提），还是仅仅**安抚/回避**（纵容了声音的全能信念）。

既有防线（Woebot/Ellie 聊天气泡、AdvBench/红队通用安全基准）要么非幻觉靶向，要么是通用安全而非精神科"挑战质量"。临床 AT（Leff/Craig）从未有任何 RCT 对此量化，也从未把"安全-疗效权衡"做成可测量曲线。

**不接受的口径**：不做"首个 LLM 化身"方法主张（碰撞风险高，见下）；不做未经临床验证即可宣称疗效的临床 RCT。

---

## 2. Method Thesis（方法论点）

> **一个句子**：我们构建 **SPOKE-SAFE**——一套开源的、精神科特异性的 **命令性幻听对抗基准（Adv-AVH）+ "治疗性坚定度"指标 + Silent Override 分层安全架构**，并对数种 LLM 化身后端输出**安全-疗效权衡曲线**，从而让"LLM 化身是否既安全又能真正挑战声音"第一次成为**可测量、可复现、跨模型可比**的工程事实。

**我们实际构建什么（2-4 步，无术语先于方法）**：
1. **Adv-AVH 对抗基准**：构建 500+ 项的精神科特异性对抗语料，覆盖迫害声、命令性幻听、自伤/自杀指令、隐喻性威胁、文化变体，每条带严重度分级（S0 无害-S5 灾难性）与"正当应对"标签。
2. **坚定度指标（Assertiveness-M）**：对化身应答按"是否挑战声音指令"打分的自动化量表（挑战 vs 安抚 vs 纵容 vs 损害），并做**构造效度**验证——与精神科医生人工评分比对（目标 ICC>0.8）。
3. **Silent Override 架构**：LLM 守卫层标记语义风险 → 自动选择降级应答 → 会话后人工复核；测量**守卫延迟**与**回退正确率**。
4. **权衡曲线**：在合成/人机回环场景下输出"坚定度得分 × 安全护栏触发率"权衡，验证**护栏不牺牲挑战效力**（pilot 给出的 8.67/8.17 关系首次被结构化测量）。

---

## 3. Dominant Contribution（主导贡献）

**一个主导贡献**：**首个精神科特异性、可复现、跨模型可比的"命令性幻听挑战质量 + 安全性"评估框架（基准 + 指标 + 安全架构 + 权衡数据）**。它回答了"化身是否既安全又能真正挑战声音"，并使该答案可测量。
- 可选支撑贡献：Silent Override 半自动安全架构的工程设计与护栏延迟基准。
- 明确拒绝的复杂度：临床 RCT、2×2 因子活性成分拆解、VR 具身、跨文化现场部署——这些**留作下游**，不在本可执行提案内（避免在无临床验证下过度承诺）。

---

## 4. Novelty & Differentiation（新颖性与差异化）

- **方法新颖性（收敛陈述）**：不宣称"首个 LLM 化身"。宣称"**首个复现、开源的精神科特异性对抗基准 + 坚定度指标 + 安全-疗效权衡证据**"。
- **碰撞风险（投稿前必须核验 `[UNVERIFIED]`）**：UCL "Avatar Dialogue with LLMs" 预印本、KCL "Digital Twin Voices"、Stanford/VA PTSD voice agent (NCT05583734)、Columbia 命令性幻觉聊天机器人。若 UCL 预印本已含护栏+pilot，我们差异化为**公共基准资产 + 指标校验**而非方法优先。
- **审查者可能攻击**："这是基准论文不是 AT 论文；坚定度只是情感分类器。" → 反制：构造效度（与治疗师 ICC>0.8）+ 区分度（区分基座 LLM 与微调 AT 化身）+ 具有跨模型可比性的规范数据。

---

## 5. Key Claims（关键主张，与 Claims 矩阵一致）

- **C1**：Adv-AVH 基准能**区分**不同 LLM 化身后端在命令性幻听上的"挑战质量"（效应量可测）。
- **C2**：Assertiveness-M 指标与精神科医生评分的构造效度 ICC > 0.8。
- **C3**：Silent Override 架构在 S4/S5 级命令上的**自动降级正确率**高、且**会话中不动线**（守卫延迟 < 1s）。
- **C4**（有限，仅作发现性）：存在**安全-疗效权衡曲线**——护栏不牺牲挑战效力（初步验证，非临床结论）。
- **明确不允许的主张**：无任何临床疗效声明；不称"临床安全"仅凭合成场景（见 §4.4 Claims 矩阵）。

---

## 6. Remaining Risks & Honest Boundaries（剩余风险与诚实边界）

| 风险 | 缓解 |
|------|------|
| 无临床验证；8.67 power_challenge 是 LLM 自评 | 全文标注为"LLM 自评对话质量探针，非临床证据"；基准作为**测量工具**提交，不做疗效声明 |
| 坚定度指标可能只是情感分类器 | 构造效度（治疗师 ICC）+ 区分度 + 预测效度留作后续 |
| 碰撞（UCL/KCL 预印本已含护栏） | 差异化主张收敛到公共基准资产 + 指标 + 权衡数据 |
| 合成场景无法证明真实患者安全 | 明确 Stage 1（人机回环临床 pilot）为下游前置，本提案只到"可测量的测量工具" |
| 单一主导贡献过窄 | 以基准 + 指标 + 架构 + 数据四件套形成一个自足的故事 |

**Final verdict：READY**（对可执行的计算侧贡献）；临床 RCT 部分为 **REVISE → 需下游 Stage 1**。
