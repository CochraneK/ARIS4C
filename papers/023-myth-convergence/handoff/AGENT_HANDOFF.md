# Agent Handoff · ARIS4C-023

Goal: build a defensible comparative study of recurrent mythic motifs without assuming similarity proves borrowing.

Immediate bounded unit:
1. freeze Pilot-0 tradition-time sample;
2. freeze motif granularity and source rules;
3. code a calibration set with provenance;
4. quantify reliability/missingness;
5. only then run headline comparative models.

Do not collapse unknown to absent; infer oral origin from earliest surviving text; treat nation/civilization labels as stable ancient cases; force QCA; or treat embedding similarity as transmission evidence.
