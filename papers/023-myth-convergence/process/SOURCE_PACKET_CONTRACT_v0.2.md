# SOURCE PACKET CONTRACT · v0.2

## Goal

All G5 coders must evaluate the **same frozen evidence boundary**. Different browsing behavior must not silently change the coding stimulus.

## Public Git contains

For every primary bundle:
- work/title;
- exact locator/bounded episode;
- canonical edition/authority;
- source URL or edition trail;
- witness scope;
- whether negative closure is permitted;
- motif definitions.

## Text delivery

When redistribution is legally safe:
- source-language/public-domain text and translation may be included in the private or public coder packet.

When a modern critical translation is copyrighted:
- do **not** commit long translated passages;
- provide the coder with the exact edition + locator through lawful access;
- where a short excerpt is necessary for coding, keep it within quotation/fair-use constraints;
- create a private packet manifest/hash at G5 intake if a non-public excerpt bundle is used.

## Identical-input rule

Human and external-model coders must use:
1. the same bundle registry version;
2. the same motif ontology version;
3. the same frozen passage boundaries;
4. the same canonical translation/edition or the same explicitly frozen excerpt packet.

If one coder cannot access the frozen source:
- code `not_observed` / source unavailable as specified;
- do not substitute a different translation silently.

## Blinding firewall

Coders must not see:
- Pilot A/B answers;
- Pilot similarity rankings;
- v0.1.1 process-tracing conclusions;
- contact-network hypotheses;
- ancestry/environment predictors;
- the label "positive control" for Ovid;
- the other v0.2 coder's answers.

The packet files omit mechanism/contact/similarity columns by design.
