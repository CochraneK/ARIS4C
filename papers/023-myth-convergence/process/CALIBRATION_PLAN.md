# Pilot-0 Calibration Plan · ARIS4C-023

## Goal

Test whether independent coders can apply motif definitions consistently across source traditions **before** any clustering, phylogenetic inference, contact model or QCA.

## Calibration families

### A. Flood / deluge — transmission-sensitive family

Core calibration traditions:
- Sumerian Flood Story;
- Old Babylonian Atrahasis;
- Standard Babylonian Gilgamesh XI;
- Genesis 6–9;
- Chinese flood/catastrophe texts as a deliberately difficult contrast.

Why: the Mesopotamian sequence provides unusually rich opportunities to distinguish textual/literary transmission from generic flood similarity. The Chinese material tests whether the ontology wrongly forces different water-disaster stories into one category.

Critical distinction:
- `catastrophic_inundation`
- `global_or_near_total_human_destruction`
- `selected_survivor`
- `warning`
- `vessel_refuge`
- `high_place_refuge`
must be coded separately.

A flood-control narrative is **not automatically** a deluge-survival narrative.

### B. Divine conflict / succession — ancestry/contact-sensitive family

Core calibration traditions:
- Hurrian-Hittite Kumarbi/Ullikummi;
- Ugaritic Baal Cycle;
- Hesiodic Theogony;
- Rigveda 1.32;
- later Babylonian material where a clearly dated source is selected.

Critical distinction:
- storm deity vs serpent;
- storm deity vs sea;
- younger-vs-older divine generation;
- succession of kingship;
- defeated body becomes cosmos.

Do not merge these simply because scholarship sometimes groups them under “chaoskampf.”

### C. Anthropogony — convergence-sensitive family

Core calibration traditions:
- Atrahasis;
- Genesis 2;
- Rigvedic anthropogonic material;
- Egyptian creator traditions only after a source-specific textual witness is frozen;
- Nüwa clay-human material as an out-of-window stress test.

Critical distinction:
- earth/clay material;
- divine blood/flesh;
- breath/speech animation;
- creation for divine labour/service;
- body dismemberment generating social/cosmic order;
- explicit “first pair.”

“Made from earth” and “formed on a potter’s wheel” are related but not identical motifs.

## Packet construction

For each coder item provide only:

1. source ID;
2. exact passage locator;
3. source-language text where licensing permits;
4. one frozen translation;
5. motif operational definition;
6. response: PRESENT / ABSENT / UNCERTAIN / NOT-OBSERVED;
7. confidence: 0–100;
8. one-sentence rationale;
9. ambiguity flag.

Do not show the other coder’s answer.

## Reliability statistics

Primary:
- Cohen’s kappa for binary-present/explicit-absent subset;
- Gwet AC1 as robustness when prevalence is extreme;
- raw agreement for four-state coding.

Secondary:
- motif-specific confusion matrix;
- confidence-weighted disagreement;
- disagreement taxonomy (definition / translation / incomplete witness / chronology / ontology overlap).

No single coefficient determines success.

## Freeze criterion

Ontology v0.1 can be frozen when:
- >= 0.80 raw agreement on scorable items;
- no recurrent disagreement caused by the same undefined boundary in >10% of packets;
- every motif has an explicit inclusion and exclusion rule;
- uncertain/not-observed handling is understood by both coders.

If prevalence makes kappa unstable, report that rather than lowering standards.

## Immediate packet target

Start with **24 motifs**:
- 8 flood;
- 8 divine-conflict;
- 8 anthropogony.

Use 4–6 source passages per family, balanced between obvious-positive, plausible-negative and ambiguous cases.

This yields a manageable reliability exercise before expanding to all 56 motifs.
