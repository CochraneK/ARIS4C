# Method Matrix · ARIS4C-023

| Question | Preferred method | Why | Main failure mode |
|---|---|---|---|
| What motifs recur? | Auditable motif coding | represents narrative units | coding drift / category imposition |
| Which traditions look similar? | Jaccard + clustering/MDS | exploratory structure | coverage mistaken for culture |
| Shared ancestry? | phylogenetic comparative methods | controls vertical inheritance | tree overreach / horizontal transfer |
| Historical contact? | contact network + dyadic/MRQAP-style model | similarity is relational | non-independence / bad contact measures |
| Plausible diffusion? | event-history + process tracing | chronology + pathway | surviving text ≠ origin |
| Ecological association? | hierarchical / phylogenetic regression | controls structured confounding | environmental determinism |
| Multiple sufficient configurations? | optional QCA/fsQCA | equifinality/configurations | arbitrary calibration |
| Textual similarity? | validated NLP embeddings, supplementary | scalable comparison | translation/model bias |
| Motif bundles? | latent class / co-occurrence network | discovers structure | overfitting/source dependence |

## Decision rule

No single method answers all mechanism families. Stronger claims require convergence across methods with different assumptions. A visually compelling similarity with no chronology/contact support remains descriptive.
