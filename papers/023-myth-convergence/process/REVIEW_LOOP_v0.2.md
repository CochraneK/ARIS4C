# ADVERSARIAL REVIEW LOOP · v0.2

Submission-grade status requires all four reviewer roles.

## Reviewer A · comparative mythology / ancient texts
Attack:
- source selection,
- translations,
- chronology,
- false equivalence of motifs,
- parallelomania,
- claims about direct dependence.

## Reviewer B · cultural evolution / phylogenetics
Attack:
- Galton's problem,
- misuse of language trees,
- reticulation/horizontal transfer,
- cross-family pseudo-distance,
- ancestral-state overreach,
- sample construction.

## Reviewer C · statistics / network / causal inference
Attack:
- dyadic non-independence,
- small-N,
- post-selection,
- overfitting,
- multiple comparisons,
- uncertainty propagation,
- causal language.

## Reviewer D · hostile replication / provenance
Try to reproduce:
- case universe,
- source bundle selection,
- coder packet,
- similarity matrix,
- model inputs,
- figures/tables,
from Git without chat memory.

## Loop
review -> issue register -> revision/reanalysis -> reviewer re-check.

Exit only when:
- no unresolved critical issue;
- major issues either fixed or explicitly convert claims from primary to exploratory;
- manuscript claims register matches outputs;
- reproducibility reviewer can reproduce all headline numbers.
