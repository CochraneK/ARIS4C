## 设置
- 模型：**C3_tree** = 树感知邻居——lineage 前缀组件距离 d=1−2L/(len_t+len_i)，w=exp(−3d)·(1+2·[同 family])·(1+0.5·[同 macroarea])，加权 Laplace (Σw·1[x=c]+1)/(Σw+K_p)，无邻居逐格回退 C1；**C4_ldm** = Bjerva 2019「潜变量+读出」无神经最小重实现——398 个 (参数,码) one-hot 槽位，soft-impute 30 轮 rank-3 SVD（缺失初值 C1），测试语言由观测槽位最小二乘读出 f_t，P(c)∝max(0, A_{p,c}·f_t)
- 任务：**single** = 每测试语言按冻结 seed 行序掩蔽 k=min(5, n_obs) 个观测格；**bundle B1/B2/B3** = 掩蔽束内 3 参数的全部观测格（B1 词序型 / B2 相邻块 / B3 rng42 随机束）
- 指标与 Pilot-0 逐字一致（logloss / brier / macro_acc / ece_10bin / reliability_slope，仅统计 掩蔽∩观测 格）

## 假设裁决与证伪状态
- **H1 预测约束：支持**（三层 h3_all AUC 均 >0.5：C3 0.57–0.79 / C4 0.73–0.78）
- **H2 语系稳健：证伪**（C3.family.single logloss 0.7820 ≥ 背景 C1 0.5252，且 ≥ 自身 random 0.7011 → 树信号在整系留出下崩塌；证伪条件 ① 触发）

- 证伪 ② 口径受限未定 · ③ 未触发 · ④⑥ 属 P3/P4 范围

## 结论（一句）
潜因子模型 C4_ldm 全面优于树感知模型 C3_tree（random single logloss 0.5396 vs 0.7011，Δ=-0.1615）且校准显著更好；但**跨组迁移缺口复现**（family 留出时 C3 退化到 0.7820，低于朴素 C1 水平；C4 0.5331 仍与 C1 0.5252 持平）→ P3 聚焦空格预测与校准，检验缺口能否被填补。
