## 本段任务
1. 读 RESEARCH_BRIEF.md，确认两条 estimands：
   - ① 跨任务结构：个体水平指标的协方差（简单辨别 / 逆转 / 负 patterning 配置 / opt-out 难度敏感度 / opt-out 增益 / opt-out 迁移）。
   - ② 试次级决策：opt-out 选择由客观难度 / 近期奖惩历史 / 潜 precision 变量谁更好预测。
   以及 M1–M5 与 claims policy。
2. 文献抽取（本段核心门控产物）：
   - 检索 *Apis mellifera* 个体水平学习与决策的已发表研究。首选 OpenAlex API（`https://api.openalex.org`，免费无 key），Crossref（`https://api.crossref.org`）补充核引用。不要用 Semantic Scholar（429）。
   - 目标任务类型：简单单向/双向辨别、逆转学习、负 patterning/配置学习、opt-out/觅食决策（尤其难度敏感 opt-out）、以及**同一批个体完成 ≥2 个任务**的研究（协方差估计依赖后者，优先）。
   - 建 `lit/REGISTRY.md`（文献登记表，分块写 ≤60 行/块，本段末尾冻结）。每研究一条，字段：
     `[序号] 标题 / 第一作者+年份 / 期刊 / DOI / 任务类型（对应上面 6 类）/ N（个体数）/ 统计量层级（A=个体水平原始数据公开可取；B=个体水平分布参数 均值/SD/方差；C=仅组水平统计）/ 关键统计量（逐项照原文报，如各组均值±SD、效应量、p 值）/ 与本课题相关性一句 / 核实状态（VERIFIED 经 Crossref DOI 核存在+元数据 / UNVERIFIED+原因）`。
   - 每条引用逐条 Crossref 核：确认存在 + 标题/年份/作者对齐。找不到就标 UNVERIFIED 并写原因，不得编造。
   - 规模控制：先做少量高精度查询（3–5 条查询 × 取 top 20），不要穷举式大规模扫；命中过多就把查询词+命中数记进 summary 再继续，不逐条全读全文。
3. 写 `data/DATA_PROFILE.md`（数据可行性画像，门控核心）：
   - 登记表研究按统计量层级 A/B/C 分桶计数，标出哪些研究涉及 ≥2 任务（同一批个体）。
   - **estimand ① 判定**：能否从文献估出个体水平跨任务协方差结构？（需要同一批个体的 ≥2 任务个体水平数据，或至少个体水平分布参数；若只有 C 级，说明研究水平 meta 分析协方差能否作降级替代。）
   - **estimand ② 判定**：能否做试次级 opt-out 回归？（需要试次级或至少 block 级 opt-out 数据/选择比例；不可得就明说。）
   - 结论：M1–M5 中哪些可估、哪些 estimand 不可行 → 给明确判定 + 替代方案（如降级研究水平 meta 分析、收窄 estimand 并在 paper.json 记录）。
   - 公开可得原始数据（仓库/论文附件）记录来源 URL + 访问状态（本段不下载，只列清单）。
4. 写 `lit/LIT_NOTES.md`：文献汇编（昆虫 GCA/个体差异、不确定性监控与 precision、期望信息增益、opt-out 范式、跨物种比较）。每研究：标题/作者/年份/来源 + 相关性一句。
