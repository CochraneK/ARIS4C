# ARIS4C019 · Decisions

## 2026-09-21 · Project created

- Primary question is longitudinal and policy-change based, not a cross-country “vacation days vs happiness” ranking.
- “Time off” is decomposed into statutory paid annual leave, public holidays, actual working hours and actual leave utilization.
- Statutory entitlement and realized time off must never be silently substituted for each other.
- Primary outcome is harmonized life evaluation / life satisfaction.
- First gate is data coverage and reform-event feasibility; do not estimate headline effects before that freeze.
- If annual global happiness coverage is insufficient, narrow the geography/time window instead of manufacturing a balanced panel.
