# ARIS4C019 · Agent handoff

## Mission

Estimate whether policy-induced or realized increases in time off are followed by changes in population subjective well-being across countries over time.

## Current state

Concept scaffold and source audit only. No effect has been estimated.

## Mandatory construct separation

Never collapse these into one “vacation” variable:

- statutory paid annual leave;
- public holidays;
- actual working hours;
- actual leave use.

## Next bounded unit

1. create country-year source coverage matrix;
2. reconstruct exact leave/work-time reform dates;
3. identify the densest defensible annual life-satisfaction series;
4. freeze inclusion rules before inspecting outcome associations;
5. produce a feasible-event table for a first staggered/event-study pilot.

## Guardrails

- no country happiness/leave ranking as causal evidence;
- no interpolation just to balance the panel;
- preserve legal definitions/tenure assumptions;
- distinguish within-country trend comparability from cross-country level comparability for hours data;
- treat Gallup access limits as a real design constraint.
