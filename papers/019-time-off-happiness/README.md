# ARIS4C-019 · Time Off × Happiness

**Working title:** Time Off and Happiness Across Countries: Longitudinal Changes in Paid Leave, Working Time, and Subjective Well-Being

ARIS4C019 asks whether increases or decreases in time off are followed by changes in subjective well-being **within countries over time**.

The project explicitly avoids the weak design of simply ranking countries by “days off” and correlating that ranking with happiness.

## Construct boundary

“Time off” is not a single variable. The project keeps at least four layers separate:

1. statutory paid annual-leave entitlement;
2. statutory public holidays;
3. actual annual / weekly hours worked;
4. actual leave utilization, when comparable data exist.

The primary causal leverage should come from policy reforms and within-country change. Cross-sectional country differences are descriptive only.
