## 1. 定义与研究范围

### 1.1 什么是计算精神病学？

计算精神病学（Computational Psychiatry）是**用形式化的数学模型来描述、解释和预测精神疾病**的一门跨学科领域。它兴起于 2010 年代，核心主张是：

> 精神疾病的症状不是"随意的功能异常"，而是**可建模的认知/计算过程失调**——这些过程可以用贝叶斯推断、强化学习、动态系统等数学框架严格刻画。

其两大支柱（据 Montague et al., 2012 经典综述）：
- **描述性（normative/mechanistic）**：哪些计算过程出了错，错在哪个环节（先验、似然、学习率、探索-利用权衡……）。
- **预测性（predictive）**：能否用计算标记（computational phenotype）预测诊断、预后、治疗反应，实现**精准精神医学**。

### 1.2 与 AI/LLM 时代的融合

计算精神病学正处于从「传统计算神经科学模型」向「机器学习和生成式 AI」融合的转折点：
- **传统**：强化学习（RL）、漂移扩散模型（DDM）、层次贝叶斯、预测编码。
- **当下**：神经影像机器学习（fMRI 分类）、数字表现型（digital phenotyping，手机/可穿戴）、**LLM 用于临床会话表征与认知建模**。

这一转向使得计算精神病学与 ARIS 的 LLM 能力天然契合。

### 1.3 与生物精神病学 / 现象学精神病学的互补

| 视角 | 核心问题 | 方法 |
|------|---------|------|
| **生物精神病学** | 大脑的分子/环路病变？ | 遗传、神经影像、生化 |
| **现象学精神病学** | 患者的主观体验结构如何改变？ | 质性分析、现象学描述 |
| **计算精神病学** | 哪种计算机制失调产生症状？ | 数学模型、AI/ML |

三者互补：计算模型可为现象学的主观体验提供**机制性解释**，也为生物标志物提供**行为/认知层面的可测量表征**。

## 2. 历史脉络

### 2.1 思想奠基期（1980s–2000s）

- **预测编码 / 自由能原理（Friston）**：大脑是"生成模型"，通过最小化自由能（预测误差）解释知觉与行动——为精神病理学提供统一框架。
- **强化学习与多巴胺（Schultz, Montague）**：多巴胺反应编码"奖励预测误差"（RPE）——为精神分裂症、成瘾、抑郁提供神经计算基础。
- **认知神经科学的计算转向**：漂移扩散模型（DDM）用于知觉决策，为行为数据提供量化解释。

### 2.2 学科正式确立期（2010s）

- **2012 年**：Montague 等在 *Nature Neuroscience* 撰文，正式提出"计算精神病学（Computational Psychiatry）"作为新学科。
- **临床可测性**：Huys, Maia, Frank 等将机器学习与精神科量表结合，提出"计算表型（computational phenotype）"概念。
- **精神分裂症的预测编码模型**（Corlett 等）：幻觉与妄想的认知模型，成为该领域最具影响力的理论之一。

### 2.3 当代扩展期（2020s–至今）

- **数据驱动的数字精神病学**：被动传感、EMA（生态瞬时评估）、自然语言处理分析临床语料。
- **生成式 AI 的介入**：LLM 用于临床访谈模拟、会话分析、认知任务生成。
- **可解释性与转化医学**：从"预测精度"走向"机制可解释 + 临床落地"的双重标准。

## 3. 核心理论框架

### 3.1 预测编码与自由能原理

- **核心机制**：大脑维护关于世界的生成模型，通过比较"预测"与"感官输入"产生**预测误差（prediction error）**，并据此更新模型（贝叶斯推断）。
- **精确度加权（precision weighting）**：误差信号的"信任权重"异常 → 各类精神病理。
- **精神分裂症**：过度关注/高估高层先验或底层感觉噪声 → 幻觉、妄想（Corlett; Fletcher & Frith 2009）。
- **自闭症**：先验相对减弱、底层感觉误差放大 → 对变化敏感、仪式化（"hypo-priors" 假说）。
- **抑郁症**：对奖赏预测的过度悲观先验 + 低精确度 → 快感缺失、习得性无助感。

### 3.2 强化学习（RL）与奖赏加工障碍

- **RPE（奖励预测误差）**：多巴胺信号的核心，量化"实际奖励 − 预期奖励"。
- **精神分裂症**：RPE 信号异常衰减 → 阴性症状、动机缺乏、奖赏学习受损。
- **抑郁症**：对负反馈的过度学习（negative learning bias）、奖赏 RPE 钝化 → 快感缺失（anhedonia）。
- **成瘾**：多巴胺超敏 + 习惯化 → 强迫性觅药。
- **焦虑/OCD**：威胁相关学习、回避学习的计算失衡。

### 3.3 证据积累（Evidence Accumulation）与决策模型

- **漂移扩散模型（DDM）**：把知觉决策建模为"证据积累到阈值"，参数（漂移率 v、边界 a、非决策时间 Ter）可解释行为。
- **精神分裂症**：漂移率降低/决策阈值升高 → 反应变慢、信心降低。
- **双相/冲动障碍**：边界（阈值）降低、冲动决策。
- **价值**：用**认知任务 + 计算模型**把主观症状转化为可量化、可复现的参数。

### 3.4 动态系统与网络视角

- **大脑作为非线性动力系统**：从稳定态到临界性、状态转换。
- **精神分裂症**：脑网络过度灵活/组织过度（hyper-organization 或过度随机），知觉-现实边界模糊。
- **抑郁症**：负面情绪状态的低迁出性（粘滞的负性吸引子）。
- **双相**：情绪状态的相变、失控的转换动力学。

### 3.5 主动推断（Active Inference）与自我

- **Friston 的主动推断**：行动 = 选择能最小化后续预测误差的动作。
- **现象学桥接**：主动推断可为"自我感/护身性（ipseity）"异常提供计算解释——直接对接 ARIS 已有的现象学精神病学方向。

## 4. 主要方法学体系

### 4.1 计算神经科学建模
- **层次贝叶斯/分层贝叶斯推断**（hierarchical Bayesian modeling）—— 用 MCMC / 变分推断拟合个体与群体参数。
- **认知模型的贝叶斯拟合**：hBayesDM（层次贝叶斯拟合 DM 系列）、Stan / PyMC。
- **生成模型**：对大脑生成模型做推断，识别"错误的先验/错误的精确度"。

### 4.2 机器学习与数据驱动
- **监督分类**：fMRI/EEG/行为特征 → 诊断分类（但临床异质性高、可解释性差）。
- **无监督/表征学习**：从高维症状数据提取计算表型（subtyping）。
- **时间序列建模**：EMA 数据的潜状态模型、隐马尔可夫模型。

### 4.3 数字表现型（Digital Phenotyping）
- **被动传感**：手机 GPS/加速度计/屏幕使用 → 运动、社交、睡眠的客观标记。
- **EMA（生态瞬时评估）**：高频率内省采样，捕捉情绪/症状动态。
- **自然语言处理**：临床访谈、社交媒体文本的语义/情感分析。

### 4.4 LLM / 生成式 AI 的新角色
- **认知任务生成与自动化**：LLM 生成个性化认知刺激、模拟被试行为。
- **临床会话表征**：对治疗会话进行结构化编码（可直接对接 avatar-therapy）。
- **计算认知建模辅助**：辅助参数推断、模型选择、结果解释。

## 5. 主要疾病领域的计算模型

| 疾病 | 核心计算机制 | 代表模型/指标 | 可测量性 |
|------|-------------|--------------|---------|
| **精神分裂症** | 预测编码失衡、RPE 衰减、感知先验过强 | 幻觉预测误差、决策漂移率 | ★★★ 认知任务可直接测量 |
| **抑郁症** | 奖赏 RPE 钝化、负性学习偏向 | 奖赏学习率、负反馈敏感性 | ★★★ |
| **双相障碍** | 情绪态转换动力学、冲动阈值 | 状态转换率、DDM 边界 | ★★ |
| **焦虑障碍** | 威胁学习、回避、过度预测 | 威胁 RPE、避免率 | ★★★ |
| **强迫症（OCD）** | 动作-结果归因异常、习惯化 | 目标导向 vs 习惯权重 | ★★★ |
| **成瘾** | 多巴胺超敏、习惯强化 | RPE 超敏、冲动选择 | ★★★ |
| **自闭症谱系** | 先验减弱、感觉误差放大 | 知觉预测误差 | ★★ |
| **创伤/PTSD** | 威胁记忆过度泛化、规避 | 泛化梯度、回避学习 | ★★★ |

## 6. 与 ARIS 现有方向的交叉点

这是**计算精神病学方向最具战略价值**的部分——它不是孤立的，而是与现有 3 个方向深度咬合：

### 6.1 ↔ Avatar Therapy（SPOKE-SAFE，最活跃主线）

- **共同问题**：如何用**可复现、跨模型可比的量化指标**评估精神科干预？
- **计算表型的供给**：avatar-therapy 的"挑战质量 + 安全"评估，可引入**计算认知指标**（如对命令性幻听的认知易感性、威胁学习参数）作为**被试端**的量化测量，补充目前"临床评分"的维度。
- **LLM 层**：两者都在用 LLM；计算精神病学可为 avatar 对话的"认知影响"提供机制解释（对话如何改变预测误差/信念更新）。
- **潜在协同**：`avatar-therapy` 的 E1（Adv-AVH 语料）可作为计算精神病学"幻觉/信念更新"任务的数据基础。

### 6.2 ↔ 现象学精神病学（Phenomenological Psychiatry）

- **机制—体验桥接**：现象学提供"主观体验结构"（护身性受损、具身异常），计算模型提供"底层机制"（预测编码失衡、主动推断）。
- **主动推断**是两者天然的连接点：它为 ipsetiy（最小自我）异常提供了计算假说。
- 可共建一个"现象学—计算"双重视角的研究计划，形成差异化贡献。

### 6.3 ↔ Prior Trial Effects（先前试验效应，工作记忆）

- **DDM/工作记忆计算模型**可直接建模"先前试验效应"（prior trial effects）——如何将前一次的刺激/反应作为先验影响当前决策。
- 现有 `prior-trial-effects` 方向（精神分裂症/双相/健康对照的工作记忆）是**计算精神病学方法应用的天然场景**：回到 RL/DDM 框架做行为建模。

### 6.4 ↔ AI 驱动的心理量表改编（ai-scale-adaptation）

- 计算表型与传统量表改编可结合：用 ML 从量表/行为数据中学习，再用 LLM 跨文化适配。

**结论**：计算精神病学可作为**横向机制层**，把现有 3 个方向的临床/现象学问题统一到"可计算的认知机制"上，提供跨研究方向的差异化方法论贡献。

## 7. 工具与基础设施

### 7.1 建模与推断
- **Stan / PyMC**：贝叶斯推断、层析模型。
- **hBayesDM**：层级贝叶斯拟合决策/RL 系列认知模型（省力、标准化）。
- **PyMC / TensorFlow Probability**：深度贝叶斯建模。

### 7.2 认知任务
- **PsychoPy**（用户已用 2022.2.5，如 Cyberball 范式）—— 搭建延迟贴现、概率学习、DDM 类任务。
- **jsPsych**：网页化认知任务的替代/互补。

### 7.3 神经影像（用户主领域：fMRI/DTI/VBM）
- **Nilearn / nilearn**：fMRI 连接与 ML 分类。
- **CONN / FSL / SPM**：功能连接与任务态分析。
- **DTI/DWI（dipy）**：结构连接与 VBM——可为计算模型提供神经底物。

### 7.4 数字表现型与 NLP
- **被动传感**：AWARE、mCerebrum。
- **NLP**：spaCy、HuggingFace 情感/语义模型；LLM 会话表征。

### 7.5 ARIS 基建
- 现有 `research-directions/*` 的模板、AGENT_GUIDE 的 W1（选题）→ W1.5（实验桥）→ W2（评审）流水线可直接复用。

## 8. 伦理与可复现性挑战

### 8.1 伦理
- **临床声明边界**：计算标记是"测量工具"，**不是临床诊断标准**——必须明确区分预测模型与临床决策。
- **数据隐私**：患者行为/神经影像/对话数据高度敏感；被动传感涉及持续位置/活动监控，需严格知情同意。
- **公平性**：ML 模型易放大社会偏见，需评估跨人群泛化性。
- **对患者的责任感**：算计模型的错误结论可能被过度解读，需透明度与人工审查。

### 8.2 可复现性（ARIS 的核心纪律）
- **任务/模型开放**：认知任务、模型代码、拟合过程需可复现（容器化、Seed 固定）。
- **区分**：量化效度（内部一致）vs 预测效度（真实临床），不能把"拟合得好"当"有临床价值"。
- **避免 p-hacking**：多模型比较需预设选择标准，用留出集/交叉验证。
- **跨模型可比**：与 avatar-therapy 相同，强调不同 LLM/模型间的公平对比（对应 ARIS `shared-references` 的实验诚实性纪律）。

## 9. 未来研究方向（3–5 条建议）

按"差异化 + 可执行 + 与 ARIS 协同"排序：

### 方向 1：幻觉/妄想的计算标记——认知任务层面的可复现基准
- **内核**：用概率学习/信念更新任务，测量精神分裂症谱系个体的"先验权重异常"，构建**公开基准 + 指标**（对齐 avatar-therapy 的 Adv-AVH 思路）。
- **优势**：计算侧完全可执行，无需临床 RCT 即产出贡献。
- **协同**：直接为 SPOKE-SAFE 提供被试端量化测量。

### 方向 2：以计算精神病学方法重建模"先前试验效应"（对接 prior-trial-effects）
- **内核**：用 DDM / 层析贝叶斯把 prior-trial-effects 建模为"先验流动"，比较精神分裂症/双相/健康对照的参数差异。
- **优势**：可复用现有方向的数据与方向感，快速产生方法学增量。

### 方向 3：现象学—计算双视角（对接 phenomenological-psychiatry）
- **内核**：用主动推断为"护身性（ipseity）异常"构造可测量模型，用认知/行为实验验证。
- **优势**：形成 ARIS 独有的跨方向差异化贡献（罕见地用计算模型检验现象学概念）。

### 方向 4：LLM 会话的信念更新建模（对接 avatar-therapy + 生成式 AI）
- **内核**：测量治疗性对话如何改变个体的"信念/预测误差更新"，用计算模型量化"对话干预的认知机制"。
- **优势**：结合 LLM 与计算建模，前沿且可执行。

### 方向 5：数字表现型 + 中文语境 EMA
- **内核**：中文语境下的被动传感/EMA 量表与数字表现特征提取。
- **优势**：填补中文计算精神病学的数据空白；但需临床落地资源，属中后期方向。

**推荐切入**：**方向 1（或与方向 2 合并）**，计算侧可立即执行、贡献清晰、与现有 avatar-therapy 主线重叠最小、协同最大。
