# Context

ARIS4C-020 studies the global ecology of scientific retractions using the complete Retraction Watch bulk dataset as the event spine, enriched with Crossref/OpenAlex for denominators, field mapping, institutions and citation trajectories.

The project is deliberately broader than descriptive bibliometrics. It separates absolute counts from rates, models publication-to-retraction lag, preserves multi-label reason structure, detects concentrated mass-retraction episodes, and studies citation persistence after retraction.

Interpretation guardrails:
- retraction is not synonymous with misconduct;
- country/institution affiliation is not responsibility;
- citations are not endorsement;
- detection and publisher policy can change observed retraction rates;
- RWDB corrections/EOCs are not population-complete.
