# Mass-Retraction / Cleanup Event Sensitivity · v1

## Motivation

A sharp annual increase in recorded retractions can be generated by a concentrated cleanup operation, conference-proceedings withdrawal, paper-mill investigation, publisher policy change, or database catch-up. It must not be interpreted automatically as a same-year increase in underlying research-integrity failures.

The frozen snapshot records 13,227 Retractions in 2023, 2.37× 2022 and 2.07× 2024. This makes concentration analysis mandatory.

## Cluster screens

At minimum screen concentration by:

- retraction year × publisher;
- retraction year × journal/source;
- retraction year × Reason;
- retraction year × publisher × high-frequency Reason;
- publication cohort × retraction year;
- Paper Mill label;
- Compromised Peer Review / peer-review issue labels;
- Computer-Aided or Computer-Generated Content.

## Descriptive metrics

For each year:
- total unique retracted works;
- top-1 / top-5 publisher share;
- top-1 / top-5 source share;
- Paper Mill share;
- peer-review-issue share;
- Herfindahl-style concentration for publisher/source;
- count of clusters exceeding a frozen minimum size/share threshold.

## Sensitivity ladder

Every headline temporal/rate result is repeated under:

A. all eligible retracted works;
B. exclude the single largest year×publisher cluster;
C. exclude all clusters exceeding the frozen mass-event threshold;
D. exclude Paper Mill-labeled works;
E. exclude Paper Mill + compromised/concern peer-review labels;
F. cap each publisher-year cluster at a fixed contribution in a robustness analysis.

These are sensitivity analyses, not attempts to define “true” versus “false” retractions.

## Event definition

Cluster screening uses **unique works**, not RWDB rows, so multiple notices for one work cannot create an artificial mass event.

## Threshold freeze

The current code exposes configurable screening thresholds but the manuscript threshold is frozen before inspecting comparative rate coefficients.

Candidate descriptive screen:
- cluster n >= 25; and
- cluster >= 2% of that retraction year's unique works.

Threshold sensitivity will be reported.

## Interpretation boundary

A concentrated cluster is an editorial/database event structure. It does not itself establish paper-mill activity, misconduct, poor publisher quality, or poor national research quality.

Specific labels such as Paper Mill are used only when present in RWDB or supported by separately sourced evidence.
