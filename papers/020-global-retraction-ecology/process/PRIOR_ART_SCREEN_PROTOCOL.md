# Prior-Art Screen Protocol · ARIS4C-020 · v1

## Purpose

This is a novelty/method-positioning screen, not a clinical systematic review and not a meta-analysis.

The screen asks whether prior empirical retraction studies already implement any of these components:

1. publication/output denominator;
2. explicit event→work identity/deduplication;
3. censoring-aware time-to-retraction;
4. native multi-label Reason/co-occurrence structure;
5. mass-retraction / cleanup sensitivity;
6. cross-database retraction-status concordance;
7. post-retraction citation trajectories.

No single component is assumed novel by itself.

## Scope

Publication years: 2010–2026 inclusive.

Eligible:
- empirical scholarly retraction datasets;
- global, multi-field, multi-country, multi-publisher or large bibliometric studies;
- method studies directly relevant to retraction status, denominator construction, lag/censoring, reasons, concentrated events, or citation afterlife;
- substantive preprints when methodologically close enough to define current novelty.

Exclude:
- purely editorial/opinion pieces without empirical retraction data;
- narrow single-case reports unless uniquely relevant to citation-afterlife or identity methodology;
- studies that only mention retractions incidentally.

## Search concepts

Core concept families:
- retraction / retracted research;
- Retraction Watch / OpenAlex / Crossref / Scopus / Web of Science / Dimensions;
- incidence / rate / denominator / exposure;
- publication-to-retraction / lag / survival / censoring;
- reason / cause / co-occurrence / taxonomy;
- paper mill / mass retraction / publisher cleanup;
- retraction metadata concordance / false retraction flag;
- post-retraction citation / citation persistence.

## Coding values

- YES: clearly implemented as an empirical method/output;
- NO: clearly outside the study's empirical package;
- PARTIAL: present but only descriptive, restricted, or not used as a sensitivity/primary method;
- UNCLEAR: insufficient evidence in the retrieved material.

For timing:
- SURVIVAL = actual time-to-event/right-censoring framework;
- CUTOFF = recent cohorts excluded/fixed maturity rule;
- DESCRIPTIVE = lag only;
- NONE / UNCLEAR.

## Freeze rule

A claimed ARIS4C-020 contribution is removed from the novelty statement as soon as a credible prior study clearly implements the same component at comparable scale.

The integrated contribution may remain defensible even when individual components have prior art.
