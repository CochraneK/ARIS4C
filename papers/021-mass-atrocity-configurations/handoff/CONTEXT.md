# ARIS4C021 · Context

User requested a new ARIS4C research project to identify necessary and sufficient configurations associated with mass atrocity/genocide onset, using an approach analogous to QCA and a periodic table.

The project is prevention-oriented comparative research. The visual periodic table is an evidence summary layer; causal status comes only from frozen set-theoretic analyses.

Direct predecessor literature identified at registration:
- Harff 2003 structural geno-/politicide risk model.
- Williams 2016 QCA over 139 genocide/non-genocide cases.

The scientific novelty target is replication + modern extension + robustness/asymmetry, not claiming that QCA has never been used in genocide research.
