# ARIS4C021 · Condition-Recovery Audit v0.1

## Why this audit exists

Recovering the 139 case identities does not imply that the six Williams condition values can be regenerated mechanically from later PITF public files.

Williams modified or supplemented several operationalizations, especially elite ideology and elite ethnicity. Later public PITF/ELC versions are useful for provenance and sensitivity checks, but cannot be assumed equivalent to his compiled matrix.

## Elite-characteristics test

Using the public EWP/PITF-2014 elite-characteristics panel and simply taking first-year values:

### 40 genocide cases
- reconstructed I (exclusionary ideology): **22**
- Williams published I: **25**
- reconstructed S (elite ethnicity salient): **34**
- Williams published S: **32**

### 102 pre-correction candidate controls
- reconstructed I: **18**
- Williams published I among 99 controls: **22**
- reconstructed S: **53**
- Williams published S among 99 controls: **45**

These discrepancies are much larger than the three-case control-universe correction can explain.

## Interpretation

The direct-public-data shortcut fails as an exact-replication strategy.

This is expected because Williams states that elite variables build on Harff/PITF coding, that unavailable cases were supplemented with qualitative coding, and that elite ethnicity was reinterpreted as political salience rather than merely copying the old minority/majority distinction.

## Rule

For each condition maintain two layers:

1. R · replication coding — reconstruct Williams's procedure as closely as documentation allows and preserve manual decisions explicitly.
2. M · modern reproducible coding — use version-pinned machine-readable sources with no undocumented manual adjustment.

Do not change public-source values merely to hit published marginal totals.

A successful historical replication must show which cells are source-derived, author-reconstructed, or unresolved.
