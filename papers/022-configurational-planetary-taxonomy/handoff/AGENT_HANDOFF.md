# AGENT HANDOFF · ARIS4C022

## Goal

Develop a scientifically defensible, reproducible configurational taxonomy of Solar-System bodies using csQCA/fsQCA, with optional descriptive clustering as a companion.

## Start here

Read:
- `../process/RESEARCH_PLAN.md`
- `../process/VARIABLES_AND_CALIBRATION.md`
- `../data/SOURCE_REGISTRY.md`

## Immediate bounded unit

Freeze the Phase-1 case list and a machine-readable data dictionary. Do **not** tune calibration based on desired planet/dwarf/satellite solutions.

## Non-negotiables

- Do not describe Mars as an unresolved planet/satellite classification.
- Do not claim QCA establishes physical causation when the outcome is a taxonomy label.
- Do not load mass, radius, density, surface gravity and escape velocity simultaneously as independent causal conditions.
- Preserve raw source values, units, uncertainty and provenance.
- Keep Solar-System IAU labels separate from any later exoplanet generalization.
