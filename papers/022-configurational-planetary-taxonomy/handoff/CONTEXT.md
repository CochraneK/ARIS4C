# CONTEXT · ARIS4C022

User requested a new ARIS4C project using QCA to compare celestial bodies, motivated by questions such as whether a body should count as a planet or satellite and by features including mass, size, gases, minerals/elements, lifecycle/evolution, distance from the Sun, and mathematical formulas.

Scientific reframing:
- “planet vs satellite” is strongly hierarchical/orbital;
- mass or size alone cannot define the class;
- Mars is already firmly a planet under current IAU rules;
- the interesting research problem is whether set-theoretic configurations reproduce, clarify, or expose tensions in existing taxonomy.

The project should eventually support a compact “periodic-table-like” comparative visualization, but the visual taxonomy must follow—not substitute for—the frozen scientific matrix.
