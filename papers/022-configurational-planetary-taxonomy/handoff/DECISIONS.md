# DECISIONS · ARIS4C022

## 2026-09-24

- Project number is 022.
- Scope is planetary-system bodies, not galaxies.
- Mars is a positive-control planet, not a genuinely disputed planet-vs-satellite case.
- QCA is used primarily as a set-theoretic/configurational taxonomy tool.
- Official category-label models are treated as definitional benchmarks, not causal discovery.
- Variable design is grouped into orbital hierarchy, dynamical dominance, self-gravity, bulk scale/structure, composition, atmosphere, thermal-geological evolution, and stellar environment.
- Mathematically derived variables are not treated as independent dimensions.
- Phase 1 is Solar System only; exoplanets are a later extension with separate scope rules.
